# Frenchify homepage quiz

`/free-french-pr-plan/` serves `next-site/public/french-pr-plan.html` through a same-domain rewrite. The HTML is the owner-supplied standalone source, served without a wrapper or a LeadConnector preview dependency. Its original Jotform submissions, email links, countdown and offer logic stay as supplied.

The results show a highlighted workshop invitation after the recommended path and answers. It links to the existing `/webinar-form/`, which displays the current workshop schedule and hosts the registration form.

This page does not invoke the retired website quiz API or its GoHighLevel workflow. No past lead records or roadmap accounts were removed. Existing learners can still sign in at `/free-french-roadmap/login/`.
